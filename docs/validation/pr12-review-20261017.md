## Local validation

Windows 11, 24 logical CPUs, Rust 1.99.1, release measurements, USearch 2.25.3.
The workspace run recorded 4,146 passing test executions in 117 suites, zero failures, and ten ignored cases. Lib and binary suites share tests, so this is not a count of distinct test definitions. The mapping benchmark was executed explicitly: one release test passed. Formatting, clippy with warnings denied, and the isolated workspace release build passed.

The first regression run failed exactly the three review defects: legacy v1 rejection, missing-sibling publication, and accepted final-byte truncation. The subsequent full run exposed six dedup fixtures missing the newly required sibling. Their fixture setup was migrated without changing assertions or the tombstone threshold.

## Mapping cost

The fixture has 100,001 symbols and 384-dimensional vectors. One reader is already open. Fixture construction and index opening are outside the timer. Three warmups precede 30 samples. Each sample checks the returned digest or complete hash list.

- Digest median: **8.8535 ms**; range 8.1440 to 11.1681 ms; p95 10.9560 ms.
- Sidecar read plus digest median: 9.0541 ms; range 8.6335 to 11.7793 ms; p95 11.3404 ms.

These are warm mapping costs, not complete HNSW-open or query latency at 100k symbols.

## Paired local API control

The previous PR12 head `4caadf4` and the review implementation use matched release builds and dependency versions. The model-free fixture has 512 symbols, 384 dimensions, and unique keys. Ten alternating process runs per side execute 1,000 public search calls each after warmup. Every call checks the exact result identity. The timer includes each graph open and validation; process startup, fixture construction, and real model inference are excluded.

Baseline median: 0.847897 ms; range 0.760815 to 0.959473 ms.
Candidate median: 0.848928 ms; range 0.806306 to 0.877347 ms.
The observed median change is +0.1215%, within the existing 10% cap. The difference is smaller than the observed variation. No speedup is claimed. The harness does not establish a runtime limiter, so a speed-difference conclusion remains inconclusive.

[Raw samples and source hashes](pr12-review-20261017.json) record the fixture hash, completed work, environment, and scope limits.
